# HWTE 專案管理系統

完整 SDLC 管理平台，支援：
- 專案立項審批
- 需求管理
- 設計、開發、測試管理
- 發布與運維

## 技術棧

- Frontend: React 18 + TypeScript + Ant Design Pro
- Backend: Node.js + Express + Prisma
- Database: PostgreSQL

## 快速開始

```bash
# 安裝依賴
npm install

# 初始化資料庫
cd backend && npm run migrate

# 啟動開發伺服器
npm run dev
```

## 專案結構

- `/frontend` - React 前端
- `/backend` - Node.js 後端
